## English (en-US)

**App name** (28):
```
Kodbuzar - Code Breaker Game
```

**Short description** (66):
```
Crack the secret 3-digit code! Logic puzzle vs computer or a friend.
```

**Full description:**
```
Kodbuzar is a fast, beautiful logic puzzle. Your opponent hides a secret 3-digit code. You have to crack it before they crack yours!

HOW IT WORKS
• Pick a secret code (the first digit can't be 0).
• Take turns guessing your opponent's code with the 3D drums.
• After every guess you get a clue: a green number shows how many digits are correct AND in the right column. A red 0 means none are.
• Digits ruled out by a 0 turn red in the columns below, so you can narrow it down like a detective. Tap any digit to mark it yourself.
• First to crack the code wins the round. Win 2 of 3 rounds to win the match!

GAME MODES
• Vs Computer: three difficulty levels (Easy, Medium, Hard). The Hard bot picks its guesses with real logic, so can you beat it?
• 2 Players (1v1): play with a friend on the same phone, with a "pass the phone" screen that hides your secret.

FEATURES
• Stunning liquid-glass 3D design with smooth animations
• Round-by-round points and speed bonuses
• Full match history and statistics
• 3 color themes: Ocean, Violet and Sunset
• Sound effects and haptic feedback
• 3 languages: English, Русский, O'zbekcha
• Works fully offline. No ads. No sign-up. No data collection.

Think. Crack. Win.
```
